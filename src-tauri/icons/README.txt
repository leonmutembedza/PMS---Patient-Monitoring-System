PMS – Patient Monitoring System icon exports

PNG sizes included:
16, 32, 48, 64, 72, 96, 128, 144, 150, 180, 192, 256, 310, 384, 512, 1024 px.

Also included:
- favicon.ico (multi-resolution)
- apple-touch-icon.png (180 x 180)

PNG files have a transparent area outside the rounded-square navy icon.
Use 192x192 and 512x512 for common PWA manifest icons.
Use favicon.ico for browser tabs.
Use apple-touch-icon.png for iOS home-screen web app icons.
Use 1024x1024 as a high-resolution master for desktop/mobile app packaging.
